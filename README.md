# kanonak.org

**Archived.** kanonak.org is built and deployed from
[kanonak-protocol/packages](https://github.com/kanonak-protocol/packages), by its `Deploy site` workflow, on every push
to its `main`. A change there is live once that run finishes.

- **The site:** <https://kanonak.org>
- **A problem with it:** an issue on [kanonak-protocol/packages](https://github.com/kanonak-protocol/packages/issues)

Until 2026-11-09 this repository held the site's deploy, which ran on a schedule and took hours to publish a change
(#12). It moved to packages in kanonak-protocol/packages#65. Its history and issues stay here to read.
